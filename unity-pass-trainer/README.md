# AR P.A.S.S. Trainer — Unity Project (`unity-pass-trainer`)

Production-ready AR fire-extinguisher trainer: Placement → PullPin → AimAtBase → SqueezeLever → SweepMotion → Extinguished / FailedOut.

**Editor:** Unity `6000.0.84f1` LTS (2022.3 is EOL/archived as of 2026; spec allows "2022.3 or newer").
Install via Hub headless:
```bash
unityhub -- --headless install --version 6000.0.84f1 \
  -m android android-sdk-ndk-tools android-open-jdk linux-il2cpp --cm
```

## Layout
| Path | Role |
|---|---|
| `Assets/Scripts/PASS/` | 7 runtime scripts (FSM, placement, pin, controller+squeeze btn, sweep tracker, fire, UI glue) |
| `Assets/Editor/ProjectSetup.cs` | One-click builder: prefabs + scene + UI + Android/XR/URP config |
| `Assets/Scenes/Main.unity` | Generated by setup (AR rig + Trainer + UI) |
| `Assets/Prefabs/` | `FireHazard`, `Extinguisher`, `ARDefaultPlane` (generated) |
| `Packages/manifest.json` | AR Foundation 6.6.2, ARCore/ARKit, URP 17.0.3, Input System 1.11.0, XR Mgmt 4.4.0 |
| `ProjectSettings/` | Bundle id `com.surakshavikas.passtrainer`, minSdk 24, IL2CPP/ARM64, Input System backend, `FireBase`/`FireUpper` tags, `Fire` layer 8 |

## Scripts (`Assets/Scripts/PASS/`)
| File | Role |
|---|---|
| `ExtinguisherFSM.cs` | Singleton state machine, whitelisted transitions, `OnStateChanged` / `OnIllegalTransition`. Guards `LeverUnlocked`, `CanSpray`. |
| `ARPlacementManager.cs` | Horizontal-only planes, tap raycast spawn, camera-child or world extinguisher, <1.8 m proximity warning. |
| `SafetyPinPuller.cs` | Drag projected on pin local axis, 5 cm breakaway, Rigidbody toss, metallic cue. Attach to PIN child. |
| `ExtinguisherController.cs` | Lever Slerp 15°, spray particles + loop, 12 s pressure → `FailedOut`, nozzle raycast FireBase/FireUpper, reticle + `AimAccuracy`. Includes `SqueezeButton` (hold UI). |
| `SweepAndCoverageTracker.cs` | Gyro yaw 0.4–2.0 rad/s gate, Left/Center/Right 2.5 s window, `RegisterSprayHit()` damage gate. |
| `FireHazard.cs` | 100 HP, flame shrink / light dim / steam grow, exact-impact `OnParticleCollision` via `GetCollisionEvents`, success `RunMetrics`. |
| `TrainingUI.cs` | Event→uGUI glue (warning, hint, health/pin/pressure bars, squeeze visibility, success/fail panels). |

## Build the scene (2 options)
**A. In Editor:** open project → let packages resolve → menu **PASS > Build Training Scene (Full Setup)**.
**B. Headless:**
```bash
<UnityEditor> -batchmode -projectPath . -executeMethod PASS.Training.Editor.ProjectSetup.BuildFromCLI -quit -logFile /tmp/setup.log
```

## Manual follow-ups after setup
1. Drop audio clips into: pin `AudioSource` (metallic), extinguisher spray loop, fire loop.
2. Verify **Project Settings > XR Plug-in Management > Android > ARCore** ticked (setup tries automatically).
3. URP: if setup warns, `Create > Rendering > URP Asset` and assign in **Graphics** settings.
4. Build to a gyro-capable Android 8+ phone; ARCore needs `minSdk 24` (already set).

## End-user run
Tap floor → fire spawns → drag pin out → aim at base (green) → hold SQUEEZE → sweep side-to-side covering L/C/R zones → metrics screen.
